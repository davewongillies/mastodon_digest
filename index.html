Hello #immich #homelab friends.

Looks like a recent update to the onnx runtime adds telemetry back to Microsoft. Because *of course* we cannot have nice things.

As far as I can tell, none of this has to do with Immich per se, it's a change to an upstream runtime. To the best of my knowledge, none of the telemetry goes to immich.

You can stop the telemetry with:
- Adding `ORT_DISABLE_TELEMETRY=1` to your `.env` file, and/or
- Using pi-hole or another ad-blocking DNS server to intercept and block the requests.

PLEASE DO NOT PILE ON THE IMMICH TEAM. This looks like a tiresome update to a dependency and not any intentional action on Immich's behalf.

More details can be found in the github issue here:

https://github.com/immich-app/immich/issues/30729
